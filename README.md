# 禾沐心理諮商所 官方網站

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 首頁 |
| `team.html` | 心理師團隊介紹 |
| `assets/site.css` | 兩個頁面共用的樣式 |
| `assets/team/` | 心理師照片 |

網站放在 Cloudflare Pages。這個 GitHub 專案一有更新，網站就會在一兩分鐘內自動更新。

## 新增一位心理師

全部都可以在 GitHub 網頁上完成，不需要安裝任何軟體。

**1. 上傳照片（沒有照片可以跳過）**

1. 在 GitHub 打開 `assets` → `team` 資料夾。
2. 按右上角「Add file」→「Upload files」，把照片拖進去。
   檔名請用英文或數字，例如 `lin.jpg`。建議直式照片，寬度 600 像素左右，檔案不要超過 300KB。
3. 按「Commit changes」。

**2. 加上介紹文字**

1. 打開 `team.html`，按右上角的鉛筆圖示（Edit）。
2. 找到「範本」那一段，複製從 `<article class="person">` 到 `</article>` 的整段。
3. 貼到「↓ 在這裡貼上心理師資料 ↓」那一行的下面。
4. 把「＿＿」換成實際內容：姓名、證書字號、專長、服務對象、諮商方式、介紹、學經歷。用不到的那一行可以整行刪掉。
5. 照片：把 `assets/team/檔名.jpg` 改成你上傳的檔名。
   沒有照片：刪掉 `<img …>` 那一行，改成 `<div class="avatar" aria-hidden="true">林</div>`（會顯示姓氏）。
6. 按「Commit changes」。

新增第一位心理師後，頁面上的「心理師介紹整理中」會自動消失。

**提醒**：請放心理師本人同意公開的資料。依《心理師法》，心理諮商所的廣告內容有限制，請確認刊登項目符合規定。
